# Improve Website Plan

## Context

- **Started:** 13 November 2026
- **Scope:** Every public Oryx Institute page counts. The journey will assess the public site as one connected experience, with priority given to pages and routes that affect factual understanding, access to current work and contact with the Oryx office.
- **Action model:** Contextual page actions. Research should lead to reading evidence; Institutional Status should lead to informed understanding; current-work, Contact and Links routes should make a factual office enquiry easy. Each phase must name one primary action for the page or flow it evaluates.
- **Problem statement:** No specific conversion problem has been established. Begin with diagnosis rather than assuming one.
- **Available evidence:** No visitor feedback, analytics, Search Console data, recordings or support data was supplied. The user reported high weekly traffic, but no source was supplied; it is a planning input only and must not be presented publicly as a measured fact.
- **Priority concern:** Visual and interaction polish.
- **Positioning baseline:** Use `src/lib/site.ts`, `src/lib/site-af.ts`, the Institutional Status page, the Register and `scrollcraft/builds/oryx-institute-2026/BRIEF.md` as constraints. These sources do not substitute for visitor evidence.
- **Public-fact guardrail:** Oryx is working toward NTA training-provider registration. It is not registered or accredited. The journey must not introduce a Directory, programme, qualification, intake, price, public-campus, leadership or regulatory-endorsement claim.
