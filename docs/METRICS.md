# Metrics

## Measurement boundary

This document records the evidence needed to improve the public Oryx Institute site. It does not claim measured traffic, conversion, demand, enquiries or outcomes. The user reported high weekly traffic during intake but supplied no source; traffic is therefore unknown for every calculation below.

Any future measurement must preserve the site's public privacy position. Do not add advertising pixels, personal profiling, unsupported performance claims or a tracking implementation without explicit approval.

## Evidence gap

A blocked artery cannot be identified because there is no verified route volume or progression data. The first missing link is an approved evidence baseline:

1. Define whether privacy-compatible aggregate measurement is appropriate.
2. Define the office-side outcome that matters after a public handoff.
3. Collect a small, consent-based sample of visitor or office-enquiry themes.
4. Record only evidence that can be verified and used without overstating demand or conversion.

- The public site must not publish or infer a programme, qualification, NQF credit, intake, price, public campus, leader, regulator partnership or endorsement.
